# Nike-website-clone
Nike-inspired frontend website website clone built with HTML and CSS

## About 
I built this project to practice and strengthen my HTML and CSS skills by recreating the structure and visual style of a modern sportswear website.

## Features 
-Responsive navigation bar 
-Sticky main navbar
-Hero section with video
-Text and buttons over the video
-Horizontal scrolling product section
-Product cards
-search ,heart and shopping-bag icons

## Tech used
-HTML5
-CSS3
-Lucide Icons

## What i learned
-flexbox
-CSS positioning
-position types and z-index
-Horizontal scrolling with 'overflow-x'
-Layering content over video
-Using browser DevTools for debugging
